4.ブラッシュアップの公式

[強いフック=リーチドライバー] ← AI/煽り/contrarian/数字
+ [原体験の1行=共感ドライバー] ← A/B/Cから1つ選択
+ [今の立ち位置/数字=信頼ドライバー] ← 月商100万 / 20万フォロワー
+ [接続CTA=フォロー転換] ← 「続きはプロフ」
─────────────────────
= 認知も共感も両取り

適用例：素材A「2年棒に振った」

会社員時代、本当に2年棒に振りました。

毎日21時退社、深夜2時にエクセル開いて、
誰のためか分からない資料を作って、
朝起きて「今日も意味なかったな」って思って通勤してた。

正直、SNSも大嫌いでした。
発信してる人見て「お前ら能天気でいいよな」って思ってた側です。

その僕が今、AIマーケの裏方で月商100万超えて
複数アカウントで総フォロワー20万人を動かしてます。

何が変わったか。
2年棒に振ったことを「自分の証明」だと気づいたこと。
